# Machine-Learning---PySpiders

This repository contains all the Machine Learning assignments and practice notebooks from PySpiders.

## 📂 Folder Structure

- **KNN/** - K-Nearest Neighbors implementations
- **XGBOOST/** - XGBoost models and tuning
- **random forest/** - Random Forest classifiers and regressors
- **logistic regression/** - Logistic regression examples, gridsearch, loan dataset
- **polynomial regression/** - Polynomial regression notebooks
- **scaling and encoding/** - Data preprocessing: scaling, encoding techniques
- **anomaly detection/** - Anomaly detection with creditcard dataset

## 🛠️ Tech Stack
- Python 3.x
- Pandas, NumPy, Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebooks
